Check the TUI sidebar before relying on an MCP server's tools.
A status dot identifies the health of each configured server, including the built-in server.

Use `/mcp status` for details and `/mcp reset [server]` to reconnect a stale server without restarting the session.
See xref:mcp.adoc[MCP support] for the connection overview.
