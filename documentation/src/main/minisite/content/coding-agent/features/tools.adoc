yca's built-in tools let the agent inspect and edit files, search a codebase, run commands, track todos and write durable memory.

== Choose a tool

* Inspect files with read, directory listing, glob and grep tools.
* Apply changes with writing, editing and patch tools.
* Run builds and other commands with `bash`.
* Track work with xref:todo-guidance.adoc[todos] and save cross-session facts in xref:memory.adoc[memory].

The generated xref:../tools.adoc[Tools reference] lists every tool's description, read-only status and JSON schema.
It is generated from the running binary.

Availability depends on configuration, the active mode and the agent profile.
Sandboxed sessions also require an adapted implementation or integration trust; some tools listed in the reference are blocked under sandbox enforcement.
MCP servers are trusted by default, not confined; see xref:../sandboxing/overview.adoc#_capability_approval_and_integration_limits[integration limits].
See xref:permissions.adoc[Permission modes] before enabling unattended tool execution.
