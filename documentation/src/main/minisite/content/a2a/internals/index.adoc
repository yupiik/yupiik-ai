== The map

[source,text]
----
io.yupiik.fusion.a2a
├── api            what an application implements: @A2ASkill, A2AExecutor, TaskUpdater, A2ASkills, A2AAgentCard
├── model          the wire model, generated from the a2a.proto - records only
├── protocol       the two bindings, the agent card endpoint, the streams, the error catalog
├── service        the operations, the task store, the skill router, the webhooks, the threads
├── signature      RFC 8785 canonicalization, and the JWS signing and verification of the agent card
└── client         A2AClient, to call another agent
----

The dependency arrows only ever point one way: `protocol` and `client` depend on `service` and `model`, `service` depends
on `api`, `signature` and `model`, `model` depends on nothing. An application only sees `api`, `model`, `signature` -
for verification - and `client`.
